# IPC benchmark — 2026-08-15

Environment: optimized `mbx 0.1.0`, x86_64 Linux/WSL, 1,000 warm PING/PONG
iterations. The Unix-socket run was performed outside the restricted development
sandbox because local socket binding was denied inside it.

```text
transport=process-per-call iterations=1000 total_ns=1288332654 mean_ns=1288332
transport=bash-coprocess iterations=1000 total_ns=572533394 mean_ns=572533
transport=unix-socket iterations=1000 total_ns=60198859 mean_ns=60198
```

Interpretation:

- Per-call startup is measurable at roughly 1.29 ms even for a no-op handshake.
- The Bash coprocess is roughly 2.25× faster and requires no socket adapter. Its
  number includes a short Bash subshell that isolates SIGPIPE so a helper crash
  cannot terminate the interactive shell.
- A persistent Unix client/server is roughly 9.5× faster than the guarded
  coprocess in this microbenchmark, but Bash cannot open Unix sockets natively.
- These are transport microbenchmarks, not complete prompt measurements. Git and
  rendering work must be benchmarked separately at p50/p95/p99.

Reproduce with:

```bash
cargo build --release --workspace
MBX_BENCH_ITERATIONS=1000 bash scripts/benchmark-ipc.bash target/release/mbx
```
